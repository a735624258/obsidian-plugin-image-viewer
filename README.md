# Obsidian 图片查看器

![version](https://img.shields.io/badge/version-1.0.0-7c3aed)
![Obsidian](https://img.shields.io/badge/Obsidian-0.15.0%2B-483699)

> **点一下笔记里的图片，就地在整窗浮层里放大看：滚轮缩放、拖拽平移、`←` `→` 翻遍这篇笔记的全部图片，`Esc` 一按回到笔记。**

**English** — Click any image in an Obsidian note to open it in a full-window overlay: wheel to zoom, drag to pan, arrow keys to step through every image in that note, `Esc` to leave. No network, no extra dependencies.

## 1、为什么要做

1. **默认点图片是"打开文件"，不是"看一眼"** —— 点下去图片被当成一个文件摊开，看完还得关掉、再找回原来那篇笔记
2. **正文宽度就是天花板** —— 笔记里的图最多显示到正文那么宽，截图里的小字放不大，细节看不清
3. **一组图没有连续性** —— 前后对比、改了几版的几张图只能一张张点开，翻起来对不上号
4. **为了看一眼要离开笔记** —— 想放大就得先导出原图、再换一个看图工具打开，代价和收益不成比例

## 2、它做什么

1. **点开就是大图** —— 点笔记里任意一张图片，整窗浮层打开，按原比例居中铺开
2. **缩放跟手** —— 滚轮或 `+` `-` 在 25% ~ 1000% 之间缩放，按住左键拖动平移，双击一键复位
3. **成组翻看** —— 当前笔记里的图片自动排成一队，`←` `→` 或两侧箭头前后翻，顶部实时显示第几张 / 共几张
4. **信息摆在明面上** —— 顶部是缩放百分比，底部是图片文件名（优先取图片的 alt 文本）
5. **不抢别人的交互** —— 带 `wrong-card` 标记这类自带点击行为的容器会主动跳过，留给原来的插件处理
6. **桌面和手机都能用** —— 移动端可以点开、拖动、左右切换（缩放只有滚轮和键盘，见 [4.4](#44-兼容性与已知坑)）

## 3、怎么用

1. 在笔记里点一张图片 —— 阅读视图、实时预览、源码模式都行，浮层会铺满整个窗口
2. 滚轮缩放，按住左键拖动平移，双击回到 100%
3. 这篇笔记里还有别的图时，用 `←` `→` 或屏幕两侧的 `‹` `›` 前后翻，顶部会显示 `2 / 5`
4. `Esc`、右上角 `✕`、或点图片以外的背景 —— 任意一个都能关闭

例子：打开一篇带三张对比截图的笔记 → 点第二张 → 浮层显示 `2 / 3` → 滚轮放大到 240% 看清小字 → `←` 翻回第一张 → `Esc` 关闭，还停在原来那篇笔记上。

| 操作 | 效果 |
|---|---|
| 滚轮上 / 下 | 放大 ×1.15 / 缩小 ×0.87，限制在 25% ~ 1000% |
| `+` `=` / `-` `_` | 放大 / 缩小 |
| 按住左键拖动 | 平移图片 |
| 双击图片 | 缩放与位移复位到 100% |
| `←` / `→` | 上一张 / 下一张 |
| `Esc` | 关闭浮层 |
| 点背景 / `✕` / `‹` `›` | 关闭 / 前后翻 |

## 4、安装

### 4.1 三条路，按需要选一条

1. **要最新版（跟 main 分支）** —— 下载仓库根目录的 `main.js`、`manifest.json`、`styles.css`，放进 `<库目录>/.obsidian/plugins/image-viewer/`
   ```sh
   git clone https://github.com/a735624258/obsidian-plugin-image-viewer.git
   ```
2. **要固定版本** —— 仓库还没打过 tag、没发过 Release，暂时没有"正式版"包可下；要锁定某个状态就 clone 之后检出对应 commit
   ```sh
   git -C obsidian-plugin-image-viewer checkout 82fc4c6
   ```
3. **要改代码** —— 把仓库 clone 到库外面，让插件目录指过去，改完重载就是新代码
   ```sh
   # Windows：目录联接
   mklink /J "<库目录>\.obsidian\plugins\image-viewer" "<仓库路径>"
   # macOS / Linux：软链
   ln -s <仓库路径> <库目录>/.obsidian/plugins/image-viewer
   ```

> 插件目录名必须是 `image-viewer` —— 跟 `manifest.json` 里的 `id` 一致，对不上 Obsidian 就认不出来。

### 4.2 装完要重载，不是自动生效

1. 先把三个文件放进 `<库目录>/.obsidian/plugins/image-viewer/`
2. 设置 → 第三方插件 → 关掉「受限模式」，在「已安装插件」里找到「图片查看器」并打开开关
3. 改代码那条路改完文件后：不用重启 Obsidian，但要把插件开关**关掉再打开**，或者 `Ctrl+R` 重载窗口；手机端重开一次 App

### 4.3 网络与卸载

1. **插件本身不联网** —— 不发请求、不上传数据，图片全部来自你自己的库
2. 只有"下载 / 更新插件"这一步要用 GitHub；HTTPS 拉不动就走 SSH（scp 形式的地址：用户名 `git`、主机 `github.com`、路径同上）
3. 卸载：设置 → 第三方插件里关掉开关，再删掉 `<库目录>/.obsidian/plugins/image-viewer/` 整个目录（设置界面里的删除按钮效果一样）
4. **卸载不留东西** —— 插件没有设置项、不写 `data.json`，也不往库里写任何文件

### 4.4 兼容性与已知坑

| Obsidian 版本 | 状态 |
|---|---|
| < 0.15.0 | 不支持，`minAppVersion` 卡在 0.15.0 |
| ≥ 0.15.0 | 预期可用；只用 `Plugin` 基类和标准 DOM 事件，没碰内部 API |

> 没有逐版回归过，出问题欢迎开 issue。

1. **只管笔记区域** —— 阅读视图、实时预览、源码模式里的图片会响应；Canvas、附件列表、其他面板里的图片不接管
2. **一次只翻一篇笔记** —— 浏览范围是当前这篇笔记里的全部图片，跨笔记翻不过去
3. **错题卡片里的图片会跳过** —— 容器带 `wrong-card` / `wrong-card-wrapper` 标记时交给原来的插件处理
4. **手机上不能缩放** —— 移动端没有滚轮和键盘，双指缩放手势没做，只能按 100% 看、拖动和左右切换
5. **文件名可能是编码串** —— 优先显示图片的 alt 文本；没有 alt 时取链接最后一段，本地图片常是一串编码后的名字
6. **暂不支持** —— 手势缩放、旋转、按文件夹连续翻页；欢迎 PR

## 5、它是怎么做到的

```
[点击]  笔记里的一张 <img>
          ↓  document 上唯一一个 click 监听（事件委托）
[判断]  在笔记区域内？落在别的插件容器里？→ 不是就放行
          ↓  收集当前笔记的全部 <img>，记住点的是第几张
[浮层]  自建 overlay 挂到 body，显示"第 n / 共 m 张"
          ↓  滚轮 / 键盘 → CSS transform 缩放 ｜ 指针捕获 → 拖拽平移
[关闭]  Esc / ✕ / 点背景 → 逐个解绑监听器、移除 DOM
```

**没有构建、没有依赖、没有后台请求** —— 整个插件就是一个 `main.js`，只做一件事：把 Obsidian 的图片点击接管过来，换成自己的浮层。

1. **一个监听器管全部图片** —— 只对 document 挂一次 click 做事件委托，笔记重渲染、图片增删都不用重新绑定；插件卸载时由 `registerDomEvent` 自动解绑
2. **缩放只改 CSS transform** —— 拖拽时 `transition: none`、缩放时才加 0.1s 过渡，所以拖动跟手、缩放平滑；不重排布局，也不复制图片
3. **指针捕获加逃生门** —— `pointerdown` 时 `setPointerCapture`，鼠标移出图片区域也能继续拖；另配 `pointerleave` 兜底，捕获万一失效也不会卡在拖拽状态
4. **关得干净** —— 关闭时逐个执行登记的 cleanup 解绑监听、移除 DOM；插件卸载（`onunload`）也会关掉当前浮层，不留残骸
5. **安全** —— 不联网、不读写库里的文件、不收集数据；只读取页面上已有的 `img.src` 来显示，不注入脚本、不加载远程资源

## 6、开发

```sh
git clone https://github.com/a735624258/obsidian-plugin-image-viewer.git
# 没有依赖要装，也没有构建步骤：main.js 就是 Obsidian 能直接加载的 CommonJS
```

> 改完不用编译 —— 把 `main.js` / `styles.css` 覆盖进插件目录，再在 Obsidian 里把插件开关关掉打开（或 `Ctrl+R` 重载窗口）就能看到效果。

```
obsidian-plugin-image-viewer/
├── manifest.json   # 元信息：id / 版本 / 最低 Obsidian 版本 / 是否仅桌面端
├── main.js         # 全部逻辑：点击接管 + 浮层 + 缩放 / 拖拽 / 切换 / 关闭
├── styles.css      # 浮层样式：遮罩、工具栏、导航按钮、进出场动画
├── CHANGELOG.md    # 版本历史
└── README.md
```

测试：仓库里没有测试目录和测试脚本，全靠手动过一遍。改完照这三条走：

1. 打开一篇有 3 张以上图片的笔记，逐张点过去，确认浮层从正确的那张开始、`n / 总数` 对得上
2. 滚轮放大到 400% 再拖到边缘，双击确认复位；`←` `→` 翻一张，确认缩放回到 100%
3. `Esc` 关掉、再点开一次点背景关掉，确认浮层消失、笔记还能正常滚动、图片还能再次点开
